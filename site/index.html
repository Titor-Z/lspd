03

接入

标准 LSP 服务器，只走 stdio。能填 command + args、能按语言绑定服务器、支持 stdio 的编辑器都能用。

Settings → Languages & Frameworks → Language Servers → +，建两条。

Name       lspd web
Command    /usr/local/bin/lspd web
Languages  HTML, CSS, SCSS, Less, Sass, JSON
Name       lspd ts
Command    /usr/local/bin/lspd ts
Languages  TypeScript, TypeScript React, JavaScript, JavaScript React

右上有 Global / This project 范围开关。内置的同类服务器要先关掉，否则两份补全互相打架。

Neovim ≥ 0.8 自带 LSP 客户端，不需要 lspconfig。

local lspd = "/usr/local/bin/lspd"

local servers = {
  { name = "lspd-web", cmd = { lspd, "web" },
    filetypes = { "html", "css", "scss", "less", "sass", "json" } },
  { name = "lspd-ts", cmd = { lspd, "ts" },
    filetypes = { "typescript", "typescriptreact",
                  "javascript", "javascriptreact" } },
}

local by_ft = {}
for _, s in ipairs(servers) do
  for _, ft in ipairs(s.filetypes) do by_ft[ft] = s end
end

vim.api.nvim_create_autocmd("FileType", {
  callback = function(args)
    local s = by_ft[vim.bo[args.buf].filetype]
    if not s then return end
    local root = vim.fs.dirname(vim.fs.find({ ".git" }, { upward = true })[1])
    vim.lsp.start({ name = s.name, cmd = s.cmd,
                    root_dir = root or vim.fn.getcwd() },
                  { bufnr = args.buf })
  end,
})

Helix ≥ 23.05，编辑 ~/.config/helix/languages.toml。

[language-server.lspd-web]
command = "lspd"
args = ["web"]

[language-server.lspd-ts]
command = "lspd"
args = ["ts"]

[[language]]
name = "html"
language-servers = ["lspd-web"]

[[language]]
name = "css"
language-servers = ["lspd-web"]

[[language]]
name = "typescript"
language-servers = ["lspd-ts"]

[[language]]
name = "tsx"
language-servers = ["lspd-ts"]

VSCode 没有「填一行命令就能用」的内置入口，需要通用 LSP 客户端扩展， 或自己写一个薄扩展用 vscode-languageclient。 另外要关掉内置的 TypeScript / HTML / CSS 服务，否则两份诊断重复。 

// extension.ts
const web = new LanguageClient("lspd-web", "lspd (Web)",
  { command: "/usr/local/bin/lspd", args: ["web"],
    transport: TransportKind.stdio },
  { documentSelector: ["html", "css", "scss", "less", "sass", "json"] });

const ts = new LanguageClient("lspd-ts", "lspd (TypeScript)",
  { command: "/usr/local/bin/lspd", args: ["ts"],
    transport: TransportKind.stdio },
  { documentSelector: ["typescript", "typescriptreact",
                       "javascript", "javascriptreact"] });

Vim 没有内置 LSP，需要 vim-lsp 或 coc.nvim。

augroup lspd
  autocmd!
  autocmd User lsp_setup call lsp#register_server({
    \ 'name': 'lspd-web',
    \ 'cmd': { server_info -> ['/usr/local/bin/lspd', 'web'] },
    \ 'allowlist': ['html', 'css', 'scss', 'less', 'sass', 'json'],
    \ })
  autocmd User lsp_setup call lsp#register_server({
    \ 'name': 'lspd-ts',
    \ 'cmd': { server_info -> ['/usr/local/bin/lspd', 'ts'] },
    \ 'allowlist': ['typescript', 'typescriptreact',
    \               'javascript', 'javascriptreact'],
    \ })
augroup END
04

安装

从 Releases 下载对应平台的压缩包，解压后是单个可执行文件。

tar -xzf lspd-v0.1.1-x86_64-apple-darwin.tar.gz
shasum -a 256 -c lspd-v0.1.1-x86_64-apple-darwin.tar.gz.sha256
sudo mv lspd /usr/local/bin/
lspd --version

编辑器从图形界面启动时拿不到终端的 $PATH，配置里一律填绝对路径。
